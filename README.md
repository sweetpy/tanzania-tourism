# Wazi

**Open Tanzania.** The open digital layer for Tanzania tourism — travellers discover and enquire; outbound operators resell via **Wazi Trade**.

Live: https://tanzania-tourism-production.up.railway.app

## Stack

- Next.js (App Router) + TypeScript
- Railway deploy via Dockerfile

## Dual audience

- Travellers: destinations, experiences, packages, enquire
- Operators (Wazi Trade): `/operators`, catalog, partner apply

## Brand

Master brand **Wazi** (Swahili: open / clear). Tagline **Open Tanzania.**
